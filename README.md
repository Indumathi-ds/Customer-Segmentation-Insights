# Customer-Segmentation-Insights
Interactive Python tool to segment customers based on demographics, income, and spending behavior. Provides insights to identify high-value and low-spending customer groups
Python tool to segment customers using **K-Means clustering** and **PCA**, visualize clusters, and provide actionable marketing insights.

## Features
- Segmented **1,500+ customers** based on demographics, income, and spending scores.
- Visualized clusters with scatter and bar charts.
- Identified **high-value and low-spending segments** for targeted campaigns.
- Generated cluster summaries and **data-driven insights**.

## Tech Stack
Python, Pandas, NumPy, Scikit-learn, Matplotlib, Seaborn, Streamlit
